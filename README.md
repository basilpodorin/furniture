# Стол Basil — шаблоны для производства

Фрезерные шаблоны (копировальное фрезерование по подшипнику / обработка на ЧПУ) для деталей стола Basil.
Геометрия берётся из «карты сборки» и DXF проекта (`source/`), размеры сверяются скриптом `src/verify.py`.

## Что в `templates/`

| Файл | Что это |
|---|---|
| `dxf/tabletop_half.dxf` | Столешница 2500×1000×40 — **половина** (1250×1000) |
| `dxf/subplate_half.dxf` | Подстолье 2450×950×24 — **половина** (1225×950) |
| `dxf/leg.dxf` | Стойка, 4 шт. (741.26 × 114.86, заготовка 70) |
| `dxf/upper.dxf` | Верхняя часть подстолья, 4 шт. (383.72 × 79.27) |
| `dxf/lower.dxf` | Нижняя часть подстолья, 4 шт. (255 × 94.51) |
| `dxf/hub.dxf` | Узел-«звезда» (140 × 135.58) |
| `dxf/sheet1_*.dxf`, `dxf/sheet2_*.dxf` | Раскладка шаблонов на 2 листа 2440×1220 (МДФ/фанера 18 мм) |
| `pdf/templates_print.pdf` | Обзор всех шаблонов + печать 1:1 на A4 для стойки, верхней/нижней части и узла (на каждом листе линейка 100 мм для проверки масштаба) |

Слои DXF: `CUT` — контур (резать), `MARK` — метки (гравировка/карандаш, не резать), `TEXT` — подписи, `SHEET` — граница листа. Единицы — мм, масштаб 1:1.

## Как пользоваться

* Контур шаблона **равен контуру детали** — для фрезы с подшипником того же диаметра. Для направляющей втулки/копир-кольца сделайте смещение в CAM.
* Столешница и подстолье симметричны по обеим осям, поэтому шаблон — половина: прямая кромка шаблона совмещается с поперечной осевой линией заготовки (метки по краям), дальше обрабатывается один торец, шаблон переворачивается — второй.  Продольная осевая метка (на торце шаблона) показывает положение оси заготовки.
* Стойки, верхние и нижние части — плоские профили, заготовка 70 мм. Зеркальную деталь получают переворотом шаблона. Заготовку 70 мм выпиливают по контуру с припуском и доводят фрезой с подшипником (при глубине больше вылета фрезы — с двух сторон).
* Синие метки на торцах — центр грани для пазов под ламели (10×30, глубина 21). Положение по длине грани — по центру (проверено по чертежу стойки).
* Перед сборкой — фаска 5 мм со всех граней (указано на чертеже; на шаблон не влияет).

## Проверить / уточнить

1. Длина стола подтверждена: **2500×1000** (2300 в `стол басил.pdf` и STL — устаревший вариант).
2. **Расстояние между двумя пазами на грани** (центр–центр) на чертежах читается неоднозначно (≈16 мм по виду узла, ≈20 мм по виду стойки), поэтому на шаблонах отмечен только центр грани, сами пазы не нарисованы.
3. **Количество узлов-«звёзд»**: в чертеже не указано; по сборке — 4 (по одному на каждый конец верхней и нижней продольной царги).
4. Продольная царга 70×1460 (2 шт.) — прямой брус, шаблона не требует.

## Сборка файлов

```
pip install -r requirements.txt
python3 src/verify.py   # сверка с исходными DXF и размерами чертежа
python3 src/build.py    # пересоздать templates/
```
